# ADR-001: Use a TypeScript JavaScript Action

- Status: Accepted (implemented)
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

Use TypeScript for maintainability and compile/bundle to a standalone JavaScript Action. Avoid a Docker Action in V1 because it adds startup latency, Linux-only execution, Docker requirements on self-hosted runners, and image supply-chain concerns.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
