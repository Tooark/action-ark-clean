# ADR-008: Apache-2.0 and open governance

- Status: Accepted (implemented)
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

License under Apache-2.0, require DCO sign-off and conventional commits, use CODEOWNERS, publish a security policy, and document release provenance and dependency posture.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
