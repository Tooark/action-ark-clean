# ADR-006: Minimize runtime dependencies

- Status: Accepted (implemented)
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

The runtime dependency target is zero: use supported Node built-ins and direct REST calls, and admit a runtime dependency only through a superseding ADR. Allow carefully pinned development tooling. Commit and verify the release bundle, publish SBOMs, and sign/prove releases.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
