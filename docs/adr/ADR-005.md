# ADR-005: Model OCI preservation as a graph

- Status: Accepted (implemented)
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

Represent indexes, platform manifests, subjects, signatures, attestations, provenance, and SBOMs as relations. Protection is propagated from retained roots. Orphan deletion requires confirmed absence rather than inference.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
