# ADR-007: Start with one package per invocation

- Status: Accepted (implemented)
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

V1 accepts one exact package name and relies on workflow matrices for multiple packages. Organization-level discovery is deferred until permission, pagination, filtering, and blast-radius controls are mature.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
