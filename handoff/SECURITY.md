# Security Policy

Do not open public issues for vulnerabilities. Report suspected token exposure, unauthorized deletion, OCI relationship breakage, workflow injection, or supply-chain compromise privately through GitHub Security Advisories for the repository.

Include the affected version/commit, minimal reproduction, expected impact, and redacted logs. Never include live tokens or private package contents.

Supported versions will be listed after the first release. Destructive security fixes may require immediate consumer pin updates and moving-major tag rotation.
