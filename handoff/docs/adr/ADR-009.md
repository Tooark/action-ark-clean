# ADR-009: Target the Node 24 Actions runtime

- Status: Proposed
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe. NFR-005 requires a supported JavaScript runtime on current GitHub-hosted runners, and the bootstrap prompt requires recording the runtime choice in an ADR.

## Decision

Use the `node24` Actions runtime (`runs.using: node24`) and require Node >= 24 for development (`engines.node`). Node 24 provides built-in `fetch`, WHATWG URL, `node:crypto`, `node:fs/promises`, and the native test runner, enabling the zero-runtime-dependency posture of ADR-006. Migrate to newer runtimes only through a superseding ADR when GitHub deprecates `node24`.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
