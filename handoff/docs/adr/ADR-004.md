# ADR-004: Treat package versions as the deletion unit

- Status: Proposed
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

Evaluate all tags attached to a version together. A single protected tag protects the version even when another tag is ephemeral. Never claim to delete only one tag when the API operation deletes the version.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
