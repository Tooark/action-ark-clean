# ADR-002: Use a functional core and imperative shell

- Status: Proposed
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

Keep discovery and deletion behind interfaces and make policy evaluation pure. This enables deterministic fixtures, mutation testing, and protection against accidental network calls during plan tests.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
