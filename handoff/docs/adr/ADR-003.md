# ADR-003: Dry-run and fail-closed defaults

- Status: Proposed
- Date: 2026-07-28

## Context

Arklean performs destructive operations against GHCR and must remain auditable, portable, and safe.

## Decision

Set dry-run true, conservative deletion budgets, preserve unknown OCI relations, and abort before any DELETE on invalid configuration, incomplete pagination, or ambiguous inventory.

## Consequences

The implementation and documentation must enforce this decision. Any exception requires a superseding ADR and migration notes.
